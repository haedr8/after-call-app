# خطوات الرفع (من الهاتف)
1. سجّل حساب مطوّر Google Play (رسوم 25$ مرة وحدة).
2. من GitHub ← Actions ← آخر تشغيل ناجح لفرع play-store ← حمّل artifact باسم haulni-aab-for-google-play (ملف .aab).
3. انشر صفحة الخصوصية (05) بعد وضع بريدك مكان EMAIL_PLACEHOLDER، وخذ رابطها.
4. Play Console ← Create app ← عربي، تطبيق، مجاني.
5. انسخ النصوص من 01/02، وأكمل النماذج من 03/04.
6. Testing ← Closed testing ← ارفع .aab ← أضف 12 بريد مختبرين ← 14 يوم.
7. بعد 14 يوم: Apply for production.
8. فعّل Play App Signing (افتراضي).
تنبيه: الإصدار هذا غير منشور على GitHub Releases ولا يتحدّث تلقائياً.
